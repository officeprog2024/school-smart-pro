01
المتطلبات الأساسية
جهّز هذه الأدوات مرة واحدة فقط
  1. ثبّت Git على جهازك.
  2. أنشئ حساباً على GitHub إن لم يكن لديك.
  3. ثبّت Node.js (إصدار LTS).

للتحقق من التثبيت:

terminal 
git --version
node --version
02
رفع المشروع لأول مرة
إنشاء repo على GitHub ورفع الكود من جهازك
  1. اذهب إلى github.com/new وأنشئ repo باسم school-smart-pro.
  2. لا تختر أي ملف افتراضي (README / .gitignore / license).
  3. افتح Terminal داخل مجلد vite-project ونفّذ:
bash 
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/school-smart-pro.git
git push -u origin main
استبدل USERNAME باسم مستخدمك على GitHub. عند أول push قد يطلب منك تسجيل الدخول عبر نافذة المتصفح.
03
تحديثات Claude — سير العمل المعتاد
عندما يُعدّل Claude ملفات المشروع
  1. حمّل الملفات المُعدَّلة (عادةً App.jsx و styles.css).
  2. استبدلها في vite-project/src/ على جهازك.
  3. أعد رفعها لـ GitHub بأمر واحد:
bash 
git add .
git commit -m "Update from Claude"
git push

أثناء التطوير، شغّل خادم Vite في نافذة Terminal منفصلة:

bash 
npm run dev
04
العمل على جهاز آخر
استنساخ المشروع من أي مكان
bash 
git clone https://github.com/USERNAME/school-smart-pro.git
cd school-smart-pro
npm install
npm run dev

لجلب آخر التحديثات إذا عدّلت من جهاز ثاني:

bash 
git pull
05
التراجع لإصدار سابق
من مزايا Git الأقوى — رجوع لأي حالة سابقة

اعرض سجل التعديلات:

bash 
git log --oneline

استرجع ملفاً معيناً من commit سابق (استبدل HASH بأول 7 أحرف من المعرّف):

bash 
git checkout HASH -- src/App.jsx

التراجع عن آخر commit مع الإبقاء على التعديلات في مجلد العمل:

bash 
git reset --soft HEAD~1
06
النشر المباشر على الإنترنت
من GitHub إلى موقع حيّ في دقائق — مجاناً

ربط مستودعك بإحدى الخدمتين، وستحدّث الموقع تلقائياً بعد كل git push:

  • Vercel — اضغط Import Project، اختر المستودع، النشر تلقائي.
  • Netlify — نفس الفكرة، يدعم Vite تلقائياً.
  • Cloudflare Pages — سرعة عالية وحدّ مجاني سخي.
كل هذه الخدمات تكتشف Vite تلقائياً ولا تحتاج إعدادات. فقط اربط حسابك بـ GitHub واختر المستودع.
07
مرجع الأوامر السريع
احفظ هذه القائمة لتجدها بسرعة
الأمرالوظيفة
git statusعرض الملفات المعدّلة وحالة العمل
git add .تجهيز كل التعديلات للـ commit
git commit -m "..."تثبيت التعديلات في السجل المحلي
git pushرفع التعديلات إلى GitHub
git pullجلب آخر التعديلات من GitHub
git log --onelineعرض سجل التعديلات بشكل مختصر
git diffعرض الفروقات بين الملفات الحالية وآخر commit
npm installتثبيت المتطلبات (بعد كل clone)
npm run devتشغيل خادم التطوير
npm run buildبناء نسخة الإنتاج
